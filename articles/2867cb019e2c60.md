# はじめに

技術学習のアウトプットを残すために、Zennの記事をGitHubで管理できる環境を構築しました。

今回は、GitHubリポジトリの作成からZenn CLIの導入、記事の作成・プレビュー、GitHubへのpushまでの流れをまとめます。

## 環境

- macOS
- Git / GitHub
- Node.js / npm
- Zenn CLI

## 1. GitHubにZenn用リポジトリを作成

GitHubで `zenn-content` というリポジトリを作成しました。

Railsなどのアプリケーションとは分けて、Zennの記事専用のリポジトリとして管理します。

## 2. ZennとGitHubリポジトリを連携する

GitHub側でリポジトリを作成したら、次にZennからリポジトリを連携します。

Zennにログインし、アカウントアイコンから「GitHubからのデプロイ」を開きます。

「リポジトリを連携する」を選びGitHubとの連携を進め、先ほど作成したZennの記事管理用リポジトリを選択します。

今回は、Zenn用として作成した `zenn-content` のみを連携しました。

GitHub側でアクセスを許可するリポジトリを選択する際は、「Only select repositories」を選択すると、Zennに必要なリポジトリだけへのアクセスを許可できます。

連携が完了すると、Zennの「リポジトリ設定」に対象のリポジトリが表示されます。

今回はデプロイ対象ブランチを `main` としました。

これで、ローカルで作成した記事をGitHubの `main` ブランチへpushすると、Zenn側へデプロイできる環境が整いました。

## 3. リポジトリをローカルへclone

作成したリポジトリをローカル環境へcloneします。

まず、ターミナルで `zenn-content` を置きたい場所に `cd` コマンドで移動します。

その後、`git clone` を使用して、作成したGitHubリポジトリをローカル環境へcloneします。

```
git clone git@github.com:アカウント名/zenn-content.git
```

cloneしたリポジトリへ移動します。

```
cd zenn-content
```

## 4. npmの初期設定

Zenn CLIをnpmで管理するため、最初にnpmの初期設定を行います。

使用コマンド：

```
npm init --yes
```

`--yes` は、初期設定でいくつか質問される項目をデフォルト値で設定するためのオプションです。

この操作によって `package.json` が作成されます。

`package.json` は、このプロジェクトで使用するnpmパッケージなどを管理するためのファイルです。

## 5. Zenn CLIをインストール

使用コマンド：

```
npm install zenn-cli
```

Zenn CLIは、ターミナルからZennの記事の作成やプレビューなどを行うためのツールです。

今回は、ローカル環境で記事を作成・確認できるようにするため、Zenn CLIをインストールしました。

コマンドを実行すると、前の手順で作成した `package.json` にZenn CLIが依存関係として追加されます。

また、主に以下のファイルやディレクトリが作成されます。

- `package-lock.json`：インストールされた依存関係やバージョンを記録
- `node_modules/`：インストールされたパッケージ本体を保存

それぞれの役割を整理すると、

- `package.json`：利用するパッケージなどを管理
- `package-lock.json`：実際にインストールされた依存関係やバージョンを記録
- `node_modules/`：インストールされたパッケージ本体を保存

となります。

## 6. Zenn用のディレクトリを作成

使用コマンド：

```
npx zenn init
```

Zenn CLIをインストールしたら、Zennの記事を管理するためのディレクトリを作成します。

`npx` を使うことで、プロジェクトにインストールしたZenn CLIを実行できます。

実行すると、主に以下のディレクトリが作成されます。

- `articles/`：記事を管理するディレクトリ
- `books/`：本形式のコンテンツを管理するディレクトリ

通常の記事は `articles/` にMarkdown形式で保存していきます。

## 7. 記事を作成

使用コマンド：

```
npx zenn new:article
```

今回は通常の記事を投稿するため、`articles/` を使用します。

コマンドを実行すると、`articles/` の中にMarkdownファイルが作成されます。

作成されたMarkdownファイルを編集して記事を書いていきます。

## 8. ローカルでプレビュー

使用コマンド：

```
npx zenn preview
```

記事を書いたら、公開前の記事がブラウザでどのように表示されるか確認します。

Markdownを編集しながら表示を確認できるため、GitHubへpushする前にレイアウトや内容をチェックできます。

## 9. GitHubへpushしてZennに反映する

ローカルで記事の内容を確認できたら、変更内容をGitHubへpushします。

まず、変更されたファイルを確認します。

```
git status
```

変更したファイルをステージングします。

```
git add .
```

コミットを作成します。

```
git commit -m "ZennとGitHubの連携手順の記事を作成"
```

GitHubの `main` ブランチへpushします。

```
git push origin main
```

GitHubへpushすると、連携しているZenn側へデプロイされます。

今回は `published: false` にしているため、この時点では記事は一般公開されません。

# まとめ

今回はZennとGitHubを連携し、ローカル環境で記事を作成・確認して、GitHubへpushするまでの環境を構築しました。

今後は、Railsの学習や個人開発で学んだことを記事として残していきたいと思います。
